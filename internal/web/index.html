    TOWN OPERATIONS

    Worker capacity

    Set the maximum number of active bot workers across all towns. Lowering the limit lets active work finish before more bots start. Reporters and issue publishing use separate capacity.

    Quiet hours

    Weekly windows, on the clock of the machine running Town, in which no new agent work starts and Town makes none of its own GitHub writes. Running work finishes, the repository is still watched, and work resumes on its own when a window ends. Every town follows this default unless its settings choose otherwise.

    Write each window as DAYS HH:MM-HH:MM and join windows with “;”. Days are mon…sun, ranges such as mon-fri, or daily, weekdays, weekends. An end at or before the start runs past midnight; 24:00 ends at midnight.
    SET ASIDE ONE TASK

    Snooze task

    Its house keeps working everything else. No agent starts and no merge happens for this task until the resume time, when it rejoins the queue on its own.

    EXTERNAL CONTRIBUTIONS

    External PRs may be reviewed, but Town never edits contributor branches. Every automatic merge still requires a clean exact-revision review, GitHub mergeability, checks, and approvals. Release Bot can create and merge its own release-preparation PRs, so the manual policy pauses it and prevents it from starting.

    Every incoming issue and pull request passes through Simplifier Bot first. In suggest mode its assessment is attached to the Mayoral decision; in auto mode routine admissions and low-value complex issue closures act without the Mayor.

    Every pull request gets one fix round. If the second review still finds work at or above this severity, Town closes the pull request and starts the issue over from the current branch. Anything below it is filed as a follow-up issue and the pull request merges.
