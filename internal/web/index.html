    Add a repository

    Brokk Town runs every bot itself; no companion CLIs are needed. Repo Bot scans the repository first and repairs the branch when its checks fail. Every other bot starts paused. Started bots resume after Brokk Town restarts.

    Connect to Brokk Town

    Run bt web and open the URL it prints. That link carries the local access key for this browser.

    Global settings

    Worker capacity

    Set the maximum number of bot workers running at once, across all repositories. Lowering the limit lets current tasks finish before more bots start. Repository scans and issue filing use separate capacity.

    Quiet hours

    Weekly windows, on the clock of the machine running Brokk Town, in which no new agent work starts and Brokk Town makes none of its own GitHub writes. Running work finishes, Repo Bot keeps watching the repository, and work resumes on its own when a window ends. Every repository follows this default unless its settings choose otherwise.

    Write each window as DAYS HH:MM-HH:MM and join windows with “;”. Days are mon…sun, ranges such as mon-fri, or daily, weekdays, weekends. An end at or before the start runs past midnight; 24:00 ends at midnight.

    Local attention hook

    Run a local command when a task is blocked. It receives public task identities and a reason code as JSON on stdin, with a ten-second limit. Hooks run independently of quiet hours. Demo mode never runs them.

    The saved command stays private. Leave blank to keep it. To remove it, disable the hook and enter []. Output stays with your command; Brokk Town discards it.

    Snooze task

    Its bot keeps working everything else. No agent starts and no merge happens for this task until the resume time, when it rejoins the queue on its own.
